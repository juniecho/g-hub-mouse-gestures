# 개요
Windows 환경에서 Logitech G HUB를 사용하여 원래는 사용하지 못하는 마우스 제스처 기능을 구현하는 Lua 스크립트로, MX Master 계열 마우스에 기본적으로 제공되는 제스처 기능을 흉내내는 것을 목적으로 함.
* MouseGesturesDESKTOP.lua와 MouseGesturesFF14.lua 2개의 스크립트로 구성되어 있으며, 각 스크립트는 독립적이며 상호의존하지 아니하므로 원하는 것을 자유롭게 선택하여 사용할 수 있음.
* https://github.com/mark-vandenberg/g-hub-mouse-gestures 에 기반하여 작성하였음.

## 설치
G HUB의 프로파일 관리 화면에서 프로파일 하단의 스크립팅 버튼을 누르고 새로운 스크립트를 등록하여 스크립트 내용을 그대로 전재, 삽입 후 저장. 제스처 버튼으로 지정된 버튼은 G HUB의 버튼 매핑 화면에서 비활성화 처리할 것.

## 기본 사용방법:
지정된 버튼(기본값: G5)을 누르며 상, 하, 좌, 우로 드래그한 후 놓거나, 동 버튼을 클릭하면 스크립트에서 지정된 키입력이 작동:
- DESKTOP: 가상 데스크톱 전환(Ctrl + Win + ←/→ 입력) 및 창 최대화, 복귀/최소화(Win + ↑/↓ 입력), 작업 표시줄 아이콘 순환 선택(Win + T 입력)
- FF14: FINAL FANTASY XIV에서 5~8번 파티원 또는 자신을 빠르게 선택하기 위하여 F5, F6, F7, F8, F1 입력

위 동작을 변경하기 위하여는 스크립트를 직접 편집하여야 함.

## 기본 동작 상세
### DESKTOP
방향 | 기능 | 입력 버튼
---- | ------- | -----------
상 | 창 최대화 | Win + ↑
하 | 창 복귀/최소화 | Win + ↓
좌 | 왼쪽 가상 데스크톱으로 이동 | Ctrl + Win + ←
우 | 오른쪽 가상 데스크톱으로 이동 | Ctrl + Win + →
클릭 | 작업 표시줄 아이콘 순환 선택 | Win + T
### FF14
방향 | 기능 | 입력 버튼
---- | ------- | -----------
상 | 5번 파티원 선택 | F5
하 | 8번 파티원 선택 | F8
좌 | 6번 파티원 선택 | F6
우 | 7번 파티원 선택 | F7
클릭 | 자기 자신 선택 | F1
